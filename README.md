# 📚 تطبيق "مكتبتي" (Maktabati)

تطبيق ويب شخصي متكامل لإدارة الكتب والمكتبات الشخصية (عربي بالكامل - RTL)، مصمم بطابع دافئ ومرن، ويعمل بشكل كامل دون إنترنت (Offline-first).

---

## 🏗️ 1. هيكل المشروع (Project Architecture)
المشروع مبني بلغة الـ Vanilla Web Stack (HTML5, CSS3, ES6 JavaScript) بدون أي إطارات عمل معقدة، ومقسّم هندسياً كالتالي:

```text
maktabati/
│
├── index.html          # الواجهة الرئيسية (UI) والنافذة المنبثقة (Modal)
├── css/
│   └── style.css       # التصميم البصري، الألوان الدافئة (Warm Palette)، وتأثيرات الـ Hover
└── js/
    ├── db.js           # طبقة إدارة قاعدة البيانات المحلية (IndexedDB CRUD Operations)
    ├── app.js          # منطق التطبيق، حساب العدادات، والفلترة الفورية
    └── backup.js       # نظام التصدير والاستيراد للنسخ الاحتياطية (JSON Backup)
